⑤ 关键帧组合：四种效果叠加在同一元素上

一条 animation 属性用逗号同时挂载 zyy_float + zyy_spin + zyy_glow + zyy_colorChange 四组关键帧

↑ 相同动画 + animation-delay 依次错开 0.2s，形成波浪节奏

核心代码

@keyframes zyy_float { 0%,100% { transform: translateY(0); } 50% { transform: translateY(-18px); } } @keyframes zyy_spin { from { transform: rotate(0); } to { transform: rotate(360deg); } } @keyframes zyy_glow { 50% { box-shadow: 0 0 34px 12px rgba(76,201,240,.85); } } @keyframes zyy_colorChange { 33% { background:#7afcff; } 66% { background:#9d8cff; } } .zyy_stage-item { animation: zyy_float 2.6s ease-in-out infinite, /* 浮动 */ zyy_spin 7s linear infinite, /* 旋转 */ zyy_glow 1.6s ease-in-out infinite, /* 发光 */ zyy_colorChange 4s ease-in-out infinite; /* 颜色渐变 */ }
