什么是 CSS 变量？

CSS 变量（又称自定义属性）允许开发者在 :root 选择器中定义可重复使用的值，然后通过 var() 函数引用它们。当需要修改主题色、字体大小等样式时，只需更改变量值即可全局生效。

/* 在 :root 中定义变量 */ :root { --zhang_primary: #4a00e0; --zhang_secondary: #8e2de2; --zhang_accent: #ffd700; --zhang_radius: 12px; --zhang_padding: 25px; } /* 使用 var() 引用变量 */ .zhang_card { background: var(--zhang_light); border-radius: var(--zhang_radius); padding: var(--zhang_padding); }

本页使用的 CSS 变量列表

  • --zhang_primary = #4a00e0 — 主色调
  • --zhang_secondary = #8e2de2 — 辅助色
  • --zhang_accent = #ffd700 — 强调色
  • --zhang_bg = #f5f7ff — 背景色
  • --zhang_text = #333333 — 文字颜色
  • --zhang_light = #ffffff — 亮色
  • --zhang_radius = 12px — 圆角
  • --zhang_shadow = 0 8px 25px rgba(74,0,224,0.15) — 阴影
  • --zhang_transition = all 0.3s ease — 过渡
  • --zhang_gradient = linear-gradient(135deg, #4a00e0, #8e2de2) — 渐变

变量效果演示

以下元素全部使用 CSS 变量控制样式，修改变量值即可统一修改外观：

按钮组件

var(--zhang_gradient) var(--zhang_radius)

标签组件

标签一 标签二 标签三

var() 函数的备用值

var() 函数可以指定第二个参数作为备用值，当变量不存在时使用：

color: var(--zhang_text, #333); font-size: var(--zhang-font-size, 16px);
