图一 · 智能客服系统流程图用户提问 → 意图识别 → 知识检索 / 人工兜底 → 回复与质检闭环

flowchart TD
    A[用户提问] --> B{渠道接入}
    B --> C[Web 网页端]
    B --> D[微信公众号]
    B --> E[App 内嵌]
    C --> F[统一网关]
    D --> F
    E --> F
    F --> G[预处理与敏感词过滤]
    G --> H{意图识别 NLU}
    H -- 常见问题 --> I[向量检索知识库 RAG]
    H -- 业务办理 --> J[调用业务接口 API]
    H -- 超纲问题 --> K[转接人工坐席]
    I --> L[LLM 生成回复]
    J --> M[组装结构化答复]
    L --> N[回复用户]
    M --> N
    K --> N
    N --> O{满意度评价}
    O -- 满意 --> P[会话归档]
    O -- 不满意 --> Q[标注反馈数据]
    Q --> R[进入评测集]
    R --> S[模型迭代训练]
    S -.持续优化.-> H
    P --> T[数据统计看板]

图二 · 知识库智能客服 ER 图用户 / 会话 / 消息 / FAQ / 知识文档 / 坐席 六大实体及关系

erDiagram
    USER ||--o{ SESSION : "发起"
    SESSION ||--o{ MESSAGE : "包含"
    AGENT ||--o{ SESSION : "接管"
    FAQ ||--o{ MESSAGE : "命中回复"
    DOC ||--o{ FAQ : "来源拆分"
    USER {
        int user_id PK
        string name
        string channel
        datetime register_time
    }
    SESSION {
        int session_id PK
        int user_id FK
        int agent_id FK
        datetime start_time
        string status
    }
    MESSAGE {
        int msg_id PK
        int session_id FK
        string role
        string content
        int faq_id FK
        datetime send_time
    }
    FAQ {
        int faq_id PK
        int doc_id FK
        string question
        string answer
        string category
        int hit_count
    }
    DOC {
        int doc_id PK
        string title
        string vector_id
        datetime update_time
    }
    AGENT {
        int agent_id PK
        string agent_name
        string skill_group
        int online
    }
实现说明：使用 mermaid@10（已本地化到 cdn/mermaid.min.js）， 在页面中直接书写 flowchart 与 erDiagram 两类 DSL 文本， mermaid 自动解析渲染为 SVG 矢量图；流程图覆盖智能客服"接入 → 识别 → 检索/兜底 → 评价 → 迭代"全链路， ER 图展示 6 个实体及其主外键关系。页面无需网络请求，双击 file:// 直接打开也可渲染。
