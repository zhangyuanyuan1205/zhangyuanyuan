Web 前端长度单位

CSS 长度单位分为「绝对单位」与「相对单位」两大类

一、绝对单位（Absolute Units）

绝对单位固定不变，不随屏幕或字体变化，浏览器会将其换算为像素（px）显示。

单位 名称 换算关系 示例
px像素1px = 1 像素font-size: 16px
cm厘米1cm = 37.8pxwidth: 2cm
mm毫米1mm = 0.1cmwidth: 10mm
in英寸1in = 96px = 2.54cmwidth: 1in
pt磅1pt = 1/72infont-size: 12pt
pc派卡1pc = 12ptwidth: 1pc

二、相对单位（Relative Units）

相对单位会随字体大小、视口尺寸或父元素变化，更适合响应式布局。

字体相关单位

em — 相对父元素字号

父元素 20px
子元素 2em = 40px

rem — 相对根元素字号

1.5rem = 24px
ex：小写字母 x 高度 · ch：数字 0 的宽度 · lh / rlh：行高

视口相关单位

1vw = 视口宽度的 1% · 1vh = 视口高度的 1% · vmin/vmax 取宽高中的较小/较大值

百分比与其他

% — 相对父元素

50% 宽度

f r — 网格弹性分数

使用小结

  • px：精确控制，适合边框、图标等固定尺寸。
  • rem：以根字号为基准，适合整体缩放与无障碍设计。
  • em：随父元素字号变化，嵌套时易累积，需谨慎使用。
  • vw / vh：随视口变化，适合全屏或响应式区块。
  • %：相对父元素，适合流式布局。
  • fr：仅用于 Grid 布局，按比例分配剩余空间。
