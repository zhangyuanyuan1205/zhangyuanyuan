什么是 JSON

  • JSON 全称 JavaScript Object Notation（JS 对象表示法）
  • 键名必须用双引号包裹，值支持六种类型
  • 数据由键值对组成，用逗号分隔
  • 不支持注释、不支持函数与 undefined
  • 数组用方括号 [ ]，对象用花括号 { }
  • 独立于语言，是前后端数据交换的事实标准

JS 对象字面量 vs JSON 字符串

JS 对象字面量
var zyy_obj = { name: '张圆圆', // 键可不加引号 age: 20, // 可用单引号 hello: function () { // 可以有函数 return 'hi'; } };

区别：键可省略引号、可用单引号、可含函数

JSON 字符串（合法）
{ "name": "张圆圆", "age": 20, "skills": ["HTML", "CSS"] }

要求：键必须双引号、无函数、无尾逗号

常见 JSON 解析错误（try...catch 捕获）

错误一：使用了单引号

{"name": '张圆圆'}

错误二：结尾多了逗号

{"name": "张圆圆",}

对照：合法 JSON

{"name": "张圆圆"}

对照：函数不是合法值

{"say": function(){}}
