技术原理

Lucide 是一种 SVG 图标方案。每个图标都是一个独立的 SVG 矢量图形， 通过 JavaScript 动态创建 SVG 元素并插入到页面中。与字体图标不同，SVG 图标可以直接通过 CSS 控制颜色、大小和样式。

1. 引入 Lucide JS

2. 使用 data-lucide 属性

3. JS 自动替换为 SVG
